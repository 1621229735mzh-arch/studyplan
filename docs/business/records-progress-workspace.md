# 记录与进度工作区

2026-10-13 用户确认：今日与计划保持现状。记录负责按时间保存与回看实际学习，进度负责按内容查看累计成果。下述结构取代第一轮的日期时间线及同期日安排对比页面。

## 记录：月 → 周 → 日

- 默认读取全部实际记录，只展开本月和本周，其他月份收起。月份标题显示学习天数及已记录累计用时，缺少用时的记录独立提示。
- 展开月份看周、展开周看实际有学习的日期。周从周一开始；跨月周在两个自然月内分别截取，记录不重复归入两个统计区间。
- 每天先按学科、课程汇总数量和用时；同课程的多次学习合并展示，展开后查看单次内容、完成量、用时与复盘。未归类的记录按任务或独立内容组织；不同单位单独分组。
- 支持本周、本月、近 30 天、自选日期、全部和科目、任务筛选。筛选统计由后端生成，只包含实际记录，不显示未完成计划项。
- 补记、修改继续使用记录页独立的 RecordEditorForm。没有任务时可补记科目、单位、完成量与用时，也可只记时长。
- 保存失败保留内容与精度；相同输入重试复用令牌，输入改变后更换令牌。修改、删除及课程归属调整检查原记录版本。
- 单次明细可修改、删除或更正课程归属；归属变更后重新汇入对应课程组，不产生新记录或第二份完成量。
- 删除需确认，统计随原记录变化。完整记录不缓存，离线不能查看完整历史或执行写操作。
- 用时折线图属于用户提出、尚待细化的想法，本轮不把它记为已交付。

## 进度：方向 → 分科 → 课程／资料 → 目录

- 首页仅显示数学、英语、政治、408 四个大方向入口。点击跳转方向详情，再进入分科、课程／资料；路径写入 URL，支持返回及刷新。
- 方向详情分别展示科目与单位的累计学习量。未归类学习量也计入累计，不能混加题、讲、页等不同单位。
- 课程展示完成量、完整总量及环形图。完整目录含未排期内容，总量由所有末级条目相加，不使用已排期量作为课程分母。
- 目录支持章节容器及末级条目。每个末级条目显示未学、学习中、已完成及真实累计数量；学科详情不以学习日期组织。
- 一门课程使用一个科目、一个单位。末级条目达到自身总量即完成；超额记录不能抵消其他未学条目。课程 `completedAmount` 对各末级项分别封顶后相加，`recordedAmount` 和学科累计保留真实数量。

## 完整目录、追加与归属

- 目录支持规范文件导入及手动维护，流程是校验 → 可读预览 → 核对完整总量变化及归属 → 确认保存。手工整理也走相同流程。
- 可从已有计划选取候选任务，并调整实际完整数量、章节及名称；候选不自动成为正式目录。任务计划量只是初始参考值。
- 导入规范、Schema、示例和当前科目／单位／任务目录可在进度页下载，详见 [目录导入说明](progress-catalog-guide.md)。文件输入仅供 Java 校验，不调用内置 AI。
- 稳定的课程 key 和目录 key 标识更新对象；新 key 追加，未提交的旧条目保留。预览列出原、新总量及全部提交条目，确认后才更新，已有学习成果保留。
- 目录结构与关联持久化在 progress 模块；实际完成量始终读取未删除学习记录，没有独立可手改的完成量副本。
- 一项任务只关联一个末级目录，科目和单位须一致；同目录可关联多项任务。历史及后续记录自动同步。
- 无明确归属的记录先计入学科累计，在方向详情的待归类列表确认具体条目；原记录页也能更正已归类记录。显式单条归属优先于任务默认归属，恢复自动归属会移除这一覆盖。
- 原记录的任务、科目或单位改变后，不匹配归属失效，返回待归类。修改、软删除原记录实时反映到目录和月份统计。
- 目录写操作共用版本与数据库锁，归类额外检查记录版本。预览 15 分钟过期，相关目录、任务、科目或单位变化后需重新预览；同令牌确认重试不重复写入。失败整笔回滚。

## 请求与离线

- 归档及目录查询由后端计算；前端负责展开和显示。旧 overview/trend API 保留兼容，不再作为进度首页内容。
- 请求切换及卸载后忽略旧响应；快照写入按顺序执行，并跳过排队时已过期的数据，避免旧响应覆盖新状态。
- 只通过现有 offline store 保存课程数量概览与学科累计，使用 `planningBasis: catalog` 及独立同步时间。不缓存完整目录节点、待归类记录或全部历史。
- 离线可以进入方向及课程概览，但完整目录和编辑、导入、归类均禁用。旧 daily 口径快照要求联网更新，身份错误不会回退旧缓存。恢复网络重新读取。
- 复习用时由复习模块管理，不重复计入首次学习量。没有自动顺延或离线写入队列。
