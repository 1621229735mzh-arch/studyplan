## 显式转换

读取任务当前版本后，通过认证接口调用：

```text
POST /api/plan/tasks/{id}/daily-practice
{ "version": 当前版本, "from": "2026-11-16", "title": "LeetCode练习" }
```

请求必须包含version、from和title。服务校验原任务为启用的SELECT_BY_NUMBER、版本未变化、生效日期不早于原开始日期；持有工作区和任务锁，在同一事务中设置无截止、每日起点，清空任务计划总量并解除原阶段目标关联。重复或过期转换返回冲突，不重建任务、不重新导入个人计划。

规划上下文导出包含dailyFrom和空endDate，Markdown显示无截止日期。旧参考安排和课程参考总量不构成题号范围或每日额度。
