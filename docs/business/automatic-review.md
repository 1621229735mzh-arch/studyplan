# 按教材自动复习（2026-11-01）

本轮用户确认：高数《基础30讲》作为一个整体收纳，实际学完的每日内容段分别进入复习循环，日期由间隔算法安排。2天只是用户举例，不是参数。此规则取代旧计划中“所有复习必须逐次手动确认”的限制，仅对明确启用自动复习的教材生效；其他内容仍按原手动流程。2026-11-01已正式发布V24并仅启用指定《基础30讲》主教材，首个真实已完成内容段已纳入；页面验收与数据保护证据见[发布记录](../operations/automatic-review-release-20261101.md)。

## 使用

复习页“按教材自动复习”中展开《基础30讲》，点击“启用自动复习”。教材身份取原按书接续 stream ID，不根据名称猜测、不修改两本书的学习计划、不默认启用《1000题》或其他教材。启用时明确提示纳入既有完整段、逾期处理和保留原手动项；以后每次学习和复习无需重复确认排期。

- 一段内容对应原接续任务。有效 `continuation_delta` 按记录日期、ID排序，累计首次达到100%的学习日为实际学完日；30%的整段不具备资格，参考排期不是完成证据。
- 首轮排在实际学完日的次日。此处是本产品的冷启动检查设置，不声称来自唯一最优科学天数表。完成100%只表明学完，不虚构记忆测试、掌握反馈或复习次数。
- 启用前已学完的段也纳入，保留实际完成日＋1；过去到期的显示逾期，不自动挪到今天。未学完的段不建立占位复习项。
- 日期视图及今日学科清单读取同一个复习项；日期视图保留 `review_item.scheduled_date`，今日执行区可推荐已逾期的自动项。每段仅有一个待执行日期，完整复习之后再计算下一次，不预建固定多轮日历。
- 整体页按教材展开到小段，显示学完日、已完整复习次数、下次日期及逾期／暂停状态；日历和日清单附教材及轮次。复习记录沿用原记录树，复习不增加首次学习量。

## 调度与反馈

### 今日逐项复习（2026-11-01 17:29:25 CST已发布）

今日按所属学科、教材收纳。每本启用教材只推荐一个当前项：当天部分完成的先继续，其余先逾期再当日到期；同类按`逾期天数 / max(1, 本轮间隔)`降序，间隔未知按1处理，同分时上次不会、模糊优先，再按原到期日、ID排序。这个排序是确定性的产品优先级，不是经个人数据训练的最优记忆模型。没有今日到期或逾期时不提前复习未来项。

打开今日、展开下一项都不写数据库、不改到期日、不伪造反馈。完成一项后下一候选为自选，点击“继续复习下一项”才展开；未开始的自选项不计入今日剩余或预计负担。保存部分进度后该项继续显示，完成仍需真实掌握反馈；下次FSRS从实际复习日计算。逾期反馈允许日期为当前学习日，旧手动项仍要求明确的安排日期，历史回看不自动带入积压。

教材／内容暂停、来源无效、任务停用和归档不进入候选；当天已真实完成的记录仍能回看。学习日09:00切换、版本、防重与离线只读沿用原规则。今日快照每本仅缓存当前推荐（或自选下一项）和当日实际痕迹，不缓存整份积压清单。

进度里的复习概览进入高等数学／操作系统等分科后才展示，四方向入口和方向概览不直接展示。分科依据来源任务的课程关联、来源记录已确认归属、同任务学习记录唯一的分科归属；没有明确来源时仅允许唯一分科兜底。同一科目有多个候选分科而来源不明时，集中到“待归类复习”，不把全科统计重复放到各分科。没有课程目录的复习使用真实科目建立分科入口。各分科的复习天数按原记录日期去重；旧subject级reviews保留兼容，新branchReviews仅是只读派生统计，进入现有概览快照，旧快照缺少它时要求同步。

采用固定的 **FSRS4Anki v5.0.0** 公开记忆模型和该版本默认19个参数，目标保持率0.9；关闭随机扰动。锁定可核对版本，不自动跟随上游或混用不同版本公式。参数及公式来源为[固定版本参考实现](https://github.com/open-spaced-repetition/fsrs4anki/blob/v5.0.0/fsrs4anki_scheduler.js)，MIT声明见[许可证](../licenses/fsrs4anki-MIT.txt)。

这是适配本站学习日的天级调度：没有分钟级学习步骤；“不会”安排到下一学习日重练。第一条真实反馈初始化记忆强度与难度；后续使用真实复习日期与上次完整复习日的间隔更新状态。部分百分比不更新模型、不推进次数、不改变下一次日期。一天只允许一次完整反馈。该保持率是模型目标，不是高数掌握率承诺；本轮不实现个人参数训练，默认参数在数学内容段上的校准仍需后续真实反馈检验。

| 现有反馈 | 含义 | 模型等级 |
|---|---|---|
| 不会 | 无法独立回忆／解题，或需要提示、查看答案后才会 | Again / 1 |
| 模糊 | 能独立完成，但回忆或解题吃力 | Hard / 2 |
| 掌握 | 能独立、顺利完成 | Good / 3 |

不使用Easy / 4入口，不把“需要提示”误当成功。先尝试回忆公式、适用条件和解题方法，独立完成代表题，再核对答案后反馈。基础原则参考[数学间隔与混合练习研究](https://digitalcommons.usf.edu/psy_facpub/1767/)及[间隔长度与保持时间研究](https://doi.org/10.1111/j.1467-9280.2008.02209.x)，不声称上述研究直接验证了本站的首轮日期或FSRS对整段高数的效果。

手动指定下次日期优先，但必须晚于本次真实复习日。更正下一次日期不会伪造一次复习，也不把拟安排日期当实际复习日期。完整复习不能发生在学完当日、过去的完整复习日之前／同日或未来学习日。

## 暂停、来源变化和并发

- 暂停一本教材会移除该教材自动项的待执行日期，保留学习、复习历史和记忆状态；再次启用恢复下一次安排。既有手动项不自动转换，不覆盖其日期或归档状态。
- 单项移除日期视为暂停该段；后台校准不能悄悄恢复，须经“恢复安排”选择日期。归档项不自动复活。
- 修改、删除来源学习记录同步重验完整资格；不足100%就暂停待执行日期，已有复习记录保留。重新学完复用原复习项，下一次日期不得早于重新学完的次日。未完成来源不能通过手动改期或反馈接口绕过。
- 写入锁顺序为任务ID升序 → 教材stream → 复习项。学习服务通过同步事务事件通知复习模块，关联写入同一事务回滚；复习模块不写学习Mapper。
- 自动反馈需要原复习项版本和提交令牌；重复请求返回原结果，不重复推进记忆或次数。令牌摘要绑定完整请求，修改反馈、日期、比例或版本后不能复用同一已成功令牌。旧手动接口兼容未提供版本的客户端。
- 自动规则开关检查版本；确认与实际完成并发时只建立一个任务来源复习项，数据库原任务唯一约束兜底。
- 学习日继续采用北京时间09:00。每分钟只校准明确启用的教材，处理未来日期记录跨截止后具备资格、停机恢复等情况；GET接口保持只读。单本失败记录日志，不影响其他教材。可用 `app.review.automatic-reconciliation-enabled=false` 关闭周期校准，学习记录保存和手动开关的同步检查仍生效。

## 接口与数据

- `GET /api/review/automatic/books`：原教材、开关与版本、已纳入段数／总段数、逾期及暂停数量。
- `GET /api/review/automatic/books/segments`：已纳入小段、完成日、下一次日期、真实复习次数与暂停原因。
- `POST /api/review/automatic/books/{streamId}`：`{"enabled":true,"version":0}`，仅按指定教材开启／暂停。
- 原安排、完整反馈和部分进度接口继续使用；自动项通过原反馈接口时必须携带 `version` 和 `clientToken`。登录、CSRF及错误响应沿用原应用。

V24只新增 `review_auto_policy`、`review_fsrs_state` 与复习记录的可空 `submission_hash`，不初始化个人规则，不改写学习记录或原复习历史。状态表存算法状态与来源资格，学习／复习事实仍来自原表。自动复习配置与明细需联网，不扩大离线缓存，也不建立离线写入。

旧复习导入v1仍只是格式规范，本功能不实现导入／来源导出、不修改其合同；自动触发通过本页的教材规则入口完成。
