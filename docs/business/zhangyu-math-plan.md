## 部分完成与延期

A、B、C表示同一本书依次安排的三份内容，每份独立记录累计完成百分比；不是整本书或整个合并任务共用一个百分比。

| 当天实际情况 | 下一日期显示 |
| --- | --- |
| A完全未做 | A；B、C往后延 |
| A完成40% | A剩余60%＋B |
| A剩余和B完全未做 | 仍是A剩余＋B，不加入C |
| 只做完A剩余，B未动 | B，不加入C |
| A收尾，B完成30% | B剩余70%＋C |
| A全部完成 | B |

只有当前新内容出现正百分比增量，才在下一日期带入后一份。只记录用时或只收尾旧内容不会推进后续新内容；漏做日期不会累计新任务名额。2026-10-30补充：本书当前内容全部完成后，当天出现“继续学习下一段”，可自选继续并逐段往后学；未开始的可选段不计入今日“还剩”或预计负担。展开不产生学习记录，实际记录百分比后才计入学习进度；两书各自提供入口。提前学习不受参考日期限制，日历保留原参考日期。

每份资料分别应用以上规则。旧内容和新内容保留原任务身份，分别填写百分比；多次记录只保存百分点增量，例如40%到70%只增加30个百分点。

2026-11-11轮换补强：昨天某本书A完全未做，今天即使轮换到其他资料，A也保留在今日清单，不收进自选；后面的B、C不会因参考日期已过而自动跳入。若A已部分完成，A剩余继续显示；由既有接续规则允许的下一段，尚未到参考日且未开始时可保持自选。完成当前段当天提供的下一段仍为自选，不因其原参考日已过而立即变成必做。旧内容保留后，今日估算可能高于原参考日估算，不宣称符合原约2.5小时的参考目标。无数据迁移或历史记录更改。
