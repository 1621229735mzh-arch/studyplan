## 每日内容格式

任务只写学习内容、练习范围和预计用时。教材细列知识点；题册使用已核实的章节及题号范围。不额外写“记录停在哪里”“填写百分比”“包含小问”等执行说明。

格式示例（教材内容已于2026-10-29按本人提供的PDF更正；完整逐日排期见下文文件）：

| 书籍 | 学习内容 | 预计用时 |
| --- | --- | ---: |
| 《基础30讲》·第1讲① | 函数、反函数、复合函数与隐函数（教材第1—8页） | 90分钟 |
| 《1000题》基础篇·第1章① | 完成第1—3题 | 30分钟 |

比例不固定为90/30或75/45；每天的新内容合计120分钟。未知页码、未核实的题号或章节题量不编造。

## 部分完成与延期

A、B、C表示同一本书依次安排的三份内容，每份独立记录累计完成百分比；不是整本书或整个合并任务共用一个百分比。

| 当天实际情况 | 下一日期显示 |
| --- | --- |
| A完全未做 | A；B、C往后延 |
| A完成40% | A剩余60%＋B |
| A剩余和B完全未做 | 仍是A剩余＋B，不加入C |
| 只做完A剩余，B未动 | B，不加入C |
| A收尾，B完成30% | B剩余70%＋C |
| A全部完成 | B |

只有当前新内容出现正百分比增量，才在下一日期带入后一份。只记录用时或只收尾旧内容不会推进后续新内容；漏做日期不会累计新任务名额。2026-10-30补充：本书当前内容全部完成后，当天出现“继续学习下一段”，可自选继续并逐段往后学；未开始的可选段不计入今日“还剩”或预计负担。展开不产生学习记录，实际记录百分比后才计入学习进度；两书各自提供入口。提前学习不受参考日期限制，日历保留原参考日期。

两本书分别应用以上规则。旧内容和新内容保留原任务身份，分别填写百分比；多次记录只保存百分点增量，例如40%到70%只增加30个百分点。
