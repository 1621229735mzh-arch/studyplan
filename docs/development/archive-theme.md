# 暗紫档案室主题

2026-10-18 用户确认本轮最后一版桌面、手机样图后实现，开发分支 `develop`。后续用户明确授权部署，已于 18:35:32 CST 正式发布并完成 PWA、桌面与手机页面验收，见[发布记录](../operations/archive-theme-release-20261018.md)。

## 设计范围

- 暗紫、灰紫与低饱和雾紫按钮，边缘保留细线观察图纹和暗红封蜡暗示。
- 人物保留茶色短发与冷静眉眼，穿暗色研究外套；窗边旧小丑笑脸气球、紫色雨雾与隐约异影构成装饰背景。不显示角色姓名。
- 今日页仍展示服务端返回的“已完成 / 进行中 / 还剩”；数量任务不创造目标分母，普通任务和按书接续仅展示已有比例。
- 桌面今日页使用左侧导航、中间清单、右侧静态插画。计划等信息密集页面使用完整内容宽度。
- 761–959px 为窄侧栏；小于等于 760px 使用底部“今日 / 计划 / 记录 / 进度 / 更多”，更多保留复习、备忘录、目标、设置、同步信息与退出。
- 小于 1200px 的今日页使用横向插画标题区。手机单列任务、操作另起一行、主要按钮至少 44px，输入文字 16px，底栏考虑安全区域；弹窗可滚动，更新提示避开底栏。
- 支持键盘焦点与跳转主要内容，减少动态效果偏好生效；插画是无交互装饰，不包含可操作控件。

本轮没有调整数据模型、API、计划、学习量、防重、并发版本检查、复习规则或离线只读边界，也没有接入模型 SDK。日期和数学“预计剩余”继续沿用原行为。

人物插画通过内置 imagegen 工具从已确认样图生成独立素材，再仅转码为 WebP；不是把完整界面截图当成网页。原图仅供生成参考，不是项目运行依赖。两张运行素材已保存至仓库。禁止把开发者绝对路径写进样式或把主题示例数据写进真实页面。

最终素材提示词摘要：

1. 桌面：提取已确认桌面样图右侧竖向插画，保留短茶发人物、研究外套、手稿、紫色雨窗、单个旧小丑笑脸气球与暖灯；去掉所有界面、文字、签名和数字。
2. 手机：提取已确认手机样图的横向标题插画，左侧保留暗部供真实标题叠放，右侧保留可辨识人物与窗边气球；去掉文字和控件，保持朦胧档案室氛围。

全局主题维护在 `styles/variables.css`，页面不得重新定义另一套 `--el-color-primary`。科目设置中的真实个人配色仍由原数据决定，不随视觉主题迁移改写。

## 首轮还原偏差与校正

用户对照设计稿与 18:35 的正式网页指出偏差：初版主要完成了配色和人物插画，缺少纸张污蚀材质，字体、图标和按钮过小，宽屏内容受最大宽度限制而出现大面积留白。不能把初版功能与构建通过视为样图已被完整还原。

校正版保持真实控件与数据，加入独立的 `archive-patina.webp`，桌面以约 14.6%／54.1%／31.3% 的比例安排侧栏、任务和插画；移除今日内容 1040px 限宽，压缩顶栏，日期与刷新收纳在标题工具区。标题和科目标题使用系统宋体衬线字族；任务字号与按钮随宽屏适度增大，按钮补充紫色矿物光泽、细边与完成／清单图标。按书内容仍保留书名、来源、原始说明与全部操作，减少树形缩进。

纹理由内置 imagegen 根据用户再次附上的确认稿生成，提示词要求提取炭黑／灰紫旧纸、墨渍、残缺绘图线、暗红细线与封蜡，移除文字、UI、人物、气球及家具，中心保留暗部。原始输出 `exec-13f4c735-92a7-4f8e-8a42-e53a8eb17c6a.png`，仅转码为 WebP。素材是装饰，不替代真实页面和可操作控件。

校正版 `pnpm.cmd run test` 仍为 116 项通过；最终 `pnpm.cmd run build` 包含类型检查并通过，PWA 预缓存 41 项（约 2281 KiB）。本地检查 1536×1024（与设计稿同尺寸）、2559×1258（与用户实际截图同尺寸）、768×1024、390×844 和 320×740，验证宽屏比例、日期选择器、手机完成弹窗及无横向溢出。截图本地演示与正式数据分别留证。

## 本地运行与验证

```powershell
cd frontend
pnpm run dev
pnpm run typecheck
pnpm run test
pnpm run build
```
