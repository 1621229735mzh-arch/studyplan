# E2E 测试（Playwright）说明

第一版前端尚未接入 Playwright 运行环境（依赖未安装，Playwright 需要单独下载浏览器）。
本目录只说明**应该覆盖哪些关键流程**，等工程基础阶段接入 CI 后再补真实用例；
在此之前，业务校验由 `tests/unit` 的 Vitest 用例覆盖。

## 环境前提

- 后端已通过 Flyway 建表，并使用真实 MySQL（Testcontainers 或本地实例）。
- 使用预设账号登录；不开放注册，因此用例不能依赖注册流程。
- 前端通过 Nginx 或 Vite 代理访问 `/api`，Cookie（SESSION）与 CSRF 请求头同域。

## 必须覆盖的流程

1. **登录与守卫**
   - 未登录访问 `/`、`/plan`、`/progress` 等页面会被重定向到 `/login`。
   - 登录失败时展示后端提示，且输入内容保留。
   - 已登录访问 `/login` 会回到首页。
   - 退出登录后，浏览器内的 IndexedDB 离线快照被清空。

2. **今日闭环（核心闭环）**
   - 今日页面展示计划量、实际完成量、剩余工作量；三者都带单位且不合成百分比。
   - 3—5 分钟完成一次学习记录：选择任务 → 填写完成量 → 填写用时 → 保存。
   - 保存成功后完成量与进度同步变化；保存失败（服务端返回错误）时不提示成功且表单内容保留。

3. **计划调整**
   - 创建任务 → 分配到本周 → 安排到某一天，并手动调整当天计划量。
   - 未完成任务不会自动出现在次日安排中（跨日期校验）。

4. **进度与统计**
   - 修改、删除学习记录后，进度概览与趋势同步变化。
   - 不同单位的数量不会出现在同一张图表系列里。

5. **复习机制**
   - 复习项只能来自已学内容；记录“不会 / 模糊 / 掌握”后下次建议日期变化。
   - 缺少预计用时或未设置额度时，界面不得出现“符合额度”的表述。
   - 未经确认的建议不会进入今日安排；确认后出现在今日复习任务中。

6. **离线只读**
   - 首次在线登录并同步后，断网（`context.setOffline(true)`）仍能查看今日、本周与进度概览，并显示最后同步时间。
   - 断网状态下尝试提交学习记录会被明确拒绝，且不进入任何上传队列。
   - 恢复网络后刷新可回到实时数据。

7. **多设备冲突**
   - 两个会话同时编辑同一条学习记录：后保存的一方看到冲突提示，而不是静默覆盖。

## 运行方式（接入后）

```bash
# 由后续工程基础阶段补充 Playwright 依赖与配置
pnpm exec playwright install
pnpm exec playwright test
```

要求：用例数据必须可重复执行（固定账号 + 可清理的测试数据），不得依赖生产环境。
